Automated Report Generation

This project is part of the ELiteTech Intern Task 2. It reads employee data from a CSV file, analyzes it, and generates a formatted PDF report using Python.

📄 Features
- Reads data from `data.csv`
- Displays employee Name, Department, and Score
- Calculates average score
- Generates a professional PDF report using the FPDF library

🛠 Technologies Used
- Python
- pandas
- fpdf

📁 File Structure

report_generator/
├── data.csv                # Input data file
├── report_generator.py     # Main Python script
├── sample_report.pdf       # Output PDF (after running the script)
└── README.md               # Project documentation


▶ How to Run

1. Install dependencies:

pip install pandas fpdf


2. Run the script:

python report_generator.py


3. Output:
A PDF file `sample_report.pdf` will be generated in the same folder.
